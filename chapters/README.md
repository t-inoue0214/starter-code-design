# 章一覧（目次）

本編は全14章（第0〜13章）です。第0章で「プログラミングの考え方」の全体像と、この教材で使う3つの軸をつかみます。その後はすべて同じ題材（注文処理）を、パターンを変えて分解していきます。

各章は、用意された神クラス（1クラスに全部入った実装）を読むところから始まります。パターンの考え方を学んだら、自分の手でクラスに分解します。分解の前後で同じテストが green になることが、リファクタリング成功の目印です。

## 3つの軸

パターンは、何を決めるための考え方かで3つの軸に分かれます。各章の冒頭に、その章がどの軸の話かを書いています。

| 軸 | 決めること | 該当する章 |
| :--- | :--- | :--- |
| ① クラスの作り方 | 部品の形と、その関係 | Part A |
| ② 業務ロジックの置き方 | ロジックをどこに、どんな形で書くか | Part B |
| ③ アプリ全体の分け方 | 責務の区画と依存の向き | Part C |
